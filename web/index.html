Blind human labelling

Label explanations as good or bad using the project's labelling guide: an explanation is good only if it is correct, complete and clear. You will not be told whether an explanation came from the baseline or the RAG system.

Labels are saved with label_source: "human" to data/labels/human_labels.jsonl and are reported separately from AI-assisted labels.

Enter your name and load an explanation.
Retrieval uses BAAI/bge-small-en-v1.5 embeddings in ChromaDB plus BM25, fused with Reciprocal Rank Fusion. Corpus: SQLite documentation (public domain) and PostgreSQL tutorials (PostgreSQL License). LLM-judge scores are automated measurements and can be wrong.
